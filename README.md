# CSC-372-Assignment-2

## Description: 

The site is used by uncg students to view upcoming events on campus. 

## Layout: 

I used flexboxes in the <main> element, and i used them to wrap the upcoming events on the homepage and the related events on the event page.

I used Grids in the event boxes in the upcoming and related cards, and in the article for the event page, and I used it on the footer. 

## Responsive Design:

I have 3 breakpoints, the first is at 950 px, where the margins on the side of the main page are removed, then at 600px the margins on the paragraphs are removed, then at 550px the info column is moved underneath the main column on the event page.

## Semantic design: 

I used the main element for the main page, as my entire article is floating above the body it is appropriate to use main here.

I used article for the text in the event cards, as there is a heading and text underneath.

I used header and footers each for their respective uses.
